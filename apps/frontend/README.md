## frontend

Hi! Welcome to the frontend for CMUHousing. This project currently uses TypeScript + Deno + React, with Vite as the bundler.

In order to start development, make sure you are in the frontend directory and install all the dependencies as follows:

```sh
cd ./apps/frontend
deno install
```

Then you can start the app with `deno run dev`, which will create a live development server that will update the page as you edit the code.

Eventually you will also have to run the backend, for now this is not needed.
